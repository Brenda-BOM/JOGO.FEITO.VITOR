# Tetris Arcade

Projeto Java com Swing, organizado em classes separadas para abrir no NetBeans.

## Como executar
1. Abra a pasta `Tetris_Colorido` no NetBeans como projeto Maven.
2. Execute a classe `tetris.Main`.

## Controles
- Setas esquerda/direita: mover a peça.
- Seta para cima: girar.
- Seta para baixo: descer uma linha.
- Espaço: queda rápida.
- F11: tela cheia.
- ESC: sair da tela cheia.

Também é possível usar os botões grandes do painel lateral.
